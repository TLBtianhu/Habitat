## 一、术语总表（旧 → 新）

| 旧 | 新 | 说明 |
|---|---|---|
| Authority / 决策管理 | **Director（认知中枢）** | 节目单、模式机、意图闸门、记忆、凭证、命令日志 |
| Worker / 身体 | **AI Client（AI 特化客户端）** | 逛网页、玩 MC、写代码、跑插件；在沙箱里 |
| Renderer / 渲染端 | **Presenter（投影/呈现）** | 舞台、形象、字幕、第一视角 |
| Outlet | **Outlet（出口）** | 编码、推流、录制 |
| MC 服务端 / 游戏服务端 | **World Service（世界服务端）** | 外部服务，世界真源；不是她的一部分 |
| 相机 bot | **Camera Client（相机客户端）** | 人类风格客户端，只负责"被看见" |
| 相位 | **模式（phase）** | PLAY / CODE / OFFLINE…；规格里沿用 phase |
| obs 编译器 | **感官层 / 观测编译器** | 把世界投影编译成给模型的快照 |
| 技能 / 插件 | **AI Client 的 mod** | 可热更、可回滚的客户端扩展 |
| 桥 | **I/O 总线** | state 上行、policy 下行，唯一跨界通道 |
| 直播客户端 | **live 适配器（热插拔）** | `streaming=true` 才注册；不开播就从工具表卸载 |
| 游戏内聊天 | **mc 适配器的通道** | 与直播弹幕不是同一个客户端，别混 |

## 一之二、两块与放置

项目只有两块：**A. AI 化的客户端适配器**（mc / live / browser / terminal），**B. 心智泵 AgentLoop**。
AgentLoop 与我们日常用的 DSH **解耦**：DSH 可作 provider，但不继承其 `pwsh` / 文件系统 / computer-use。
放置：**心智在 Windows（窄工具面），身体在 WSL，世界与眼睛在 Windows 或外部**；凭证只在 Windows。

## 三、已经定下的（不再讨论）

1. 播出不可中断，但组件可崩；Presenter 与 Outlet 在隔离边界外。
2. 播放头永不撒谎：宁可黑场/待机，不定格。
3. 她能改的只有可弃层；自迭代层可整块删除。
4. 观众名字落盘、头像只存 URL；折叠队列只显示条数；礼物提高进批次概率但不插队。
5. `PLAY` 与 `CODE` 永不同时"可操作"。
6. **世界只有一个真源，两个客户端：有脑子的（AI Client）与只有眼睛的（Camera Client）。**
7. **换世界 = 换槽**；不开播 = 关投影；联机 = 多一个玩家。
8. **渲染器必须认识世界版本**；相机必须是服务端承认的玩家（RCON `/tp`）。
