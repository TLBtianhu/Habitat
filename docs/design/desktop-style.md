# Habitat Desktop 视觉风格：把桌面与任务栏做得有前端精美感

> 2026-11-01 · 参考：Material Design 3、Fluent Design、GNOME HIG、Tailwind/shadcn 的现代前端审美、Lucide 图标体系。

## 1. 设计目标

- **安静**：不是炫酷游戏机，而是一个长期在线的桌面；
- **清晰**：当前应用、后台状态、正在说什么，一眼可辨；
- **克制**：少阴影、少发光、少装饰，靠排版与层级取胜；
- **一致**：SVG renderer 与未来的 Nuklear backend 共用同一套设计令牌。

## 2. 设计令牌

### 色彩

| 用途 | 值 |
|---|---|
| 桌面底色 | `#0B0F14` |
| 主表面 | `#111827` |
| 抬升表面 | `#172033` |
| 边框 | `#243247` |
| 主文字 | `#E6EDF7` |
| 次文字 | `#94A3B8` |
| 弱文字 | `#64748B` |
| 主 accent | `#7C9EFF` |
| 成功 | `#34D399` |
| 警告 | `#FBBF24` |
| 危险 | `#FB7185` |

### 形状与间距

- 8pt 网格：所有间距取 8 的倍数；
- 圆角：卡片 16px、任务栏 18px、小控件 10px；
- 页面边距：32px；
- 卡片内边距：20–24px；
- 阴影：只用一层很轻的 `0 12px 32px rgba(0,0,0,.28)`，不要霓虹发光。

### 字体

- 首选 **Inter / Noto Sans SC**；
- 标题 20–24px、正文 14–16px、辅助 12–13px；
- 正文行高 1.5，避免过密。

## 3. 任务栏设计

不要“Windows 开始菜单”感，做成**居中的浮动 Dock**：

- 高度 56px，左右留白 24px；
- 半透明深色底 + 轻微 blur；
- 当前应用：accent 色 pill + 细描边；
- 后台应用：普通 pill，只有事件时出现一个小圆点；
- 关闭应用：**不显示**，不要摆一排灰图标；
- 图标优先用 Lucide 风格线性图标，不用 emoji 充当主图标。

## 4. 主画面与 PiP

- 主应用卡片占视觉中心，圆角 16px；
- PiP 固定 16:9，最多两个，不任意叠窗；
- 主应用标题区只放：应用名、状态、一个主操作；
- 观众不需要知道的所有内部状态，不要堆到画面上。

## 5. 动效

- 160–220ms，ease-out；
- 切换用淡入淡出 + 轻微位移，不要弹跳；
- 后台通知只让徽标出现/消失，不闪烁；
- 提供 reduce-motion：直接切换，无动画。

## 6. 与 Nuklear 的关系

Nuklear 只负责画控件，不负责审美决策。它也应该吃同一套令牌：

- 背景、表面、边框、文字、accent；
- 圆角、间距、字体大小；
- 任务栏的 focused/background/closed 三态。

这样 SVG renderer 与原生 backend 看起来是同一个桌面，而不是两套皮肤。

## 7. 反例

- 不要大面积玻璃拟态导致文字对比度下降；
- 不要满屏小部件；
- 不要“灰掉的关闭应用”占任务栏；
- 不要靠高饱和色区分所有状态，状态主要靠文字与位置，颜色只做辅助。
