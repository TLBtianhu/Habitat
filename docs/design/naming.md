## 为什么不是"AI 直播"

直播只是她的一种能力，不是她的定义。一个部署实例可以同时：

- 在 QQ 群里当一个独立账号；
- 在 MC 里当一个独立玩家（可常驻某服，但不绑定某服）；
- 在直播间当一个主播（她自己决定开不开）；
- 在模组生态里当一个贡献者。

这些交互共享同一个身份、记忆与承诺。社区价值来自**同一个意识体在多个场域持续存在**，不是来自"会开播"。

## 技术对应

- **AgentLoop**：持续的事件泵，驱动 observe → decide → act；
- **客户端插件**：qq / mc / live / ide / browser / terminal，按需装卸；
- **Identity Hub**：统一身份，客户端只见 identityId 与短期 token；
- **无头显示器**：把各客户端状态投影给观众，不拥有它们的状态；
- **长生命周期**：session 交接、承诺账本、记忆压缩，比"播多久"更重要。

## 一句话定位

> **Habitat 是一个让持续意识体长期生活的地方；大肥鱼是住在里面的第一个居民。**
