# 三种形态与路径解耦

## 编译中间物（开发环境）

- 只用于构建便携版/安装包，不是分发形态；
- 必须保持纯净：不写设置、缓存、索引、聊天、记忆、模型或 token；
- 不进入用户开始菜单，也不作为日常运行入口；
- 构建失败只影响中间物，不污染发行目录。

## 便携版

- 拷到任意位置即可自包含运行；
- 'app/'、'runtime/'、'data/'、'config/' 可放在同一便携目录旁；
- 不写注册表，不依赖系统 JDK/npm/pip，不要求管理员；
- 可与开发目录、安装版同时存在。

## 安装版

- 应用可安装到系统目录或用户安装目录；
- 安装版才拥有注册表、文件关联和卸载入口；
- 配置与用户数据放 '%APPDATA%/Habitat'，大模型/缓存放 '%LOCALAPPDATA%/Habitat/cache'；
- 卸载默认保留配置、记忆、模型和用户数据，只有明确 purge 才清理；
- 安装版由 WSL 当前用户的 supervisor 启停，使用独立 102xx 端口和 data/config，不借用开发现实例的 systemctl 服务；
- 默认不连接外部应用；缺 LLM 配置时显示 configuration_required，不伪造人格在线；
- 控制台设置中心可随时修改配置，保存与生效状态分离，secret 仅在本机内存中使用且不回显。

### Windows 只保留两个 EXE

- `HabitatSetup.exe`：单文件安装包，嵌入应用、runtime lock 和安装脚本，负责安装、升级、回滚和卸载；默认当前用户，不要求管理员；
- `HabitatConsole.exe`：由安装包释放到客户端目录，打开 Windows 控制台，不承载 AgentLoop、插件进程或推流；
- 不在 Windows 分别安装 QQ、MC、语音等后台服务；这些客户端与它们真正的服务器按部署拓扑连接。

### 签名发布

- 普通 CI 的自签名测试只验证签名结构、时间戳和哈希，不作为生产信任声明；
- 正式签名发布必须配置生产 PFX secrets，通过证书链、RFC3161 时间戳和签名后哈希验收；
- 未配置生产证书时不得发布“受信任签名版”。

开发用编译中间物，日常用安装版或便携版；开发者和普通用户不是同一顶帽子。
